¿Cómo descargarlo?

**Opción 1: Descargar el código**
1. Entra al repositorio de GitHub.
2. Haz clic en el botón verde **Code**.
3. Selecciona **Download ZIP**.
4. Descomprime el archivo y ábrelo en el programa correspondiente.

También puedes clonarlo desde GitHub usando la opción **Clone**.

**Opción 2: Descargar la APK (Android)**
1. Entra a la sección **Releases** del repositorio.
2. Busca la versión más reciente.
3. Descarga el archivo `.apk` en tu celular.
4. Abre el archivo e instala la aplicación. Si Android solicita permiso para instalar aplicaciones de esa fuente, autorízalo únicamente si confías en el archivo.

## Reporte de errores y sugerencias

Si encuentras algún error al utilizar la aplicación o tienes alguna sugerencia para mejorarla, puedes dejar tu comentario en la sección **Issues** de este repositorio.

1. Entra a **Issues**.
2. Haz clic en **New issue**.
3. Selecciona **Reporte de Incidencia o Sugerencia**.
4. Describe el problema o la sugerencia.
5. Agrega una captura de pantalla si es necesario.
6. Envía tu comentario.

Los comentarios recibidos serán revisados para realizar las correcciones o mejoras necesarias.
O igualmente puedes comentar en la sección de "Discussion"
